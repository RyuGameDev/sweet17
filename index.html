📷 Panduan Mengisi / Mengganti Media

Kamu bisa langsung mengganti media dengan cara menaruh filemu di folder assets/ atau mengubah config.js:

1. Foto Polaroid (8 Foto)

Cukup ganti file di folder assets/ dengan nama yang sama:

  • assets/photo1.jpg s/d assets/photo8.jpg

2. Video Pesan

Ganti file: assets/video.mp4

3. Musik / Lagu Latar

Ganti file: assets/music.mp3

4. Teks, Tanggal & Surat Cinta

Buka file config.js di editor. Di sana kamu bisa mengubah teks surat, tanggal hitung mundur, doa, dan nama sesukamu!
